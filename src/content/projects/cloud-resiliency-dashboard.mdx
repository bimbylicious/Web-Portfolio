## Overview

Capstone project for Southville International School and Colleges, CITE, defended
May 2026. The dashboard lets a user build a network topology on a drag-and-drop
canvas and simulate cascade failures, load-balancer behavior, and auto-scaling
against it, watching resilience metrics update live.

## Architecture

The app runs two simulation engines that coexist in the same codebase:

- **Active, client-side simulation engine**: a Zustand store holds all topology
  and runtime state in-browser, bridged into the existing React Query cache so
  the Dashboard and Resources pages render simulator data exactly as they would
  render live backend data. The `/topology` page provides the canvas, node
  palette, load-balancer config panel, simulation controls, and an event log.
- **Legacy, backend-driven simulation**: an Express API with Prisma/PostgreSQL
  and node-cron worker jobs (system evaluator, failover executor, health
  checker, auto-scaler, threshold evaluator). This pipeline is fully preserved
  for capstone documentation and can be re-enabled via environment flags, but is
  disabled by default in favor of the faster, backend-free client-side engine.

## Validation

User testing produced a System Usability Scale score of 80/100 (rated "Good" on
the SUS grading scale) and a System Acceptance Questionnaire mean of 5.86/7. The
frontend also carries 365 automated tests across 16 test files, covering the
simulation engine, the Zustand store, topology validation, and the React Query
bridge.
