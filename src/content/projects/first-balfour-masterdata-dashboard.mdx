## Overview

Built during an on-the-job training placement at First Balfour, this is an
internal employee management system with role-based access for admins and
regular users.

## Features

- Google OAuth 2.0 authentication with admin and regular-user roles
- Employee CRUD with soft-delete and restore
- Excel import/export for bulk employee data
- PDF clearance document generation with signature support
- Automated database backups
- Audit logging for every data change
- Rate limiting and session management

## Stack

A Node.js/Express/TypeScript backend on PostgreSQL (Supabase), authenticated via
Passport.js and Google OAuth, with a React, Vite, and Tailwind CSS frontend.
