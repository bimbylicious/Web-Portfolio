## Overview

A finals project for Programming 2: a Windows desktop application (WPF, C#)
for tracking enrollment leads at Southville International School and Colleges.

## Features

- New lead intake form with a live webcam capture screen (built on AForge.NET)
  for attaching a photo to each lead record
- Lead listing and management views (menu, lead table)
- Document generation for lead records
- Local data storage via LINQ to SQL

## Stack

Built entirely on the .NET Framework using WPF for the UI and LINQ to SQL for
data access, with AForge.NET handling webcam capture.
